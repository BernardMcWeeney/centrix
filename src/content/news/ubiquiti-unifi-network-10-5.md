Ubiquiti’s [Network 10.5 announcement](https://blog.ui.com/article/introducing-network-10-5) focuses on reducing disruption during network changes and making faults easier to investigate.

Test & Confirm adds confirmation safeguards for configuration changes on UniFi access points and switches, with rollback if connectivity is lost. Link Debounce and Auto STP Edge aim to reduce unnecessary topology disruption. The release also brings a more connected view of client activity for troubleshooting.

## Why it matters

Remote changes are particularly sensitive when a business depends on a single connection or has no technical staff on site. These safeguards can help, but Centrix still recommends a configuration backup, an agreed maintenance window and a recovery route before changing production equipment.

Ubiquiti also describes expanded SAML options in Site Manager Early Access. Treat those separately from generally available application features and check the release channel before planning deployment.
