Microsoft’s [September security update](https://www.microsoft.com/en-us/security/blog/2026/09/24/whats-new-in-microsoft-security-september-2026/) includes generally available network data protection through Microsoft Purview and Entra Global Secure Access. Microsoft describes controls that can identify sensitive information and block transfers to risky destinations, including unsanctioned AI tools.

The update also covers Security Copilot summaries of email detonation results, Purview auto-labelling improvements and expanded eDiscovery coverage for content in Copilot-related experiences.

## What to review in Microsoft 365

Centrix’s practical takeaway is to start with the information that needs protection and the tools staff already use. Labels, sharing permissions and retention rules need to reflect the business before additional controls can work well.

Check licensing and deployment requirements for each feature. These capabilities are not automatically included or configured in every Microsoft 365 subscription. Our [Microsoft security assessment](/services/microsoft-365/security-assessment) can help identify the next useful changes.
