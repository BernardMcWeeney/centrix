Ubiquiti has announced [UniFi Network 11](https://blog.ui.com/article/introducing-unifi-network-11), describing a redesigned telemetry engine, live traffic flows for devices connected to a UniFi Gateway and Time Machine Topology to review network changes over time.

The release also develops security, connectivity and Matter device management. Ubiquiti claims more than 30% better telemetry scalability; that is a vendor figure rather than a Centrix benchmark.

## Better visibility needs a planned upgrade

For businesses, historical topology and traffic views can help an administrator understand what changed when a connection stopped working. They are especially useful when network documentation needs to reflect changes across several sites.

Centrix recommends checking console, gateway and application compatibility against the official release notes before upgrading. Back up the configuration, allow a maintenance window and test essential services afterwards.
