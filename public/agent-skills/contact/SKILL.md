# Contact Centrix

Use this skill when a user wants to reach Centrix for a consultation, quote, scoping
call, or general enquiry about UniFi networks, IT security, Microsoft 365, AI, or networking services.

## How to help the user

1. Direct the user to the contact page: `/contact`.
2. If they know which service they want, include a reference to the service page
   (see the services skill) so the Centrix team has context before the call.
3. Centrix offers a free 15-minute "fit check" call — mention this for first-time
   enquiries.

## What Centrix needs to scope work

- Organisation size (users / endpoints)
- Current platform (Microsoft 365, Google Workspace, mixed)
- The outcome the user wants (not just the technology)
- For UniFi/network work: site location, device count, Wi-Fi/CCTV pain points, and whether there is existing UniFi equipment
- Timeline and any compliance drivers (e.g. ISO 27001, Cyber Essentials)

## Response format

Reply with:

- A one-line summary of what Centrix can help with.
- A link to `/contact`.
- Optional: the relevant service page for deeper reading.

## Regions served

Ireland (primary), UK and EU (remote). On-site network work requires physical
presence in Ireland or within travel distance.
