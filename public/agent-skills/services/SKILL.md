# Centrix Service Catalogue

Use this skill when a user asks what Centrix does, what services are available, or
wants to find a specific engagement (e.g. "penetration test", "Copilot readiness",
"Intune setup").

## Four pillars

Centrix organises its work under four pillars. Each has a dedicated landing page:

- **Security** — `/security` — penetration testing, vulnerability management,
  incident response, SOC-lite monitoring, attack surface management.
- **Microsoft** — `/microsoft` — Microsoft 365 security, Intune, Defender,
  Conditional Access, Entra ID, Purview, Copilot readiness.
- **AI** — `/ai` — AI readiness, governance, workflow automation, staff training,
  pilot programs.
- **Networks** — `/networks` — UniFi full-stack design, implementation, site
  technology, managed network operations.

## Flagship productised services

Every engagement is fixed scope, clear deliverables, predictable price. Key offers:

- Microsoft 365 Security Assessment (5–10 days)
- Penetration Testing (1–2 weeks)
- Conditional Access Hardening (1–2 weeks)
- Intune Baseline Implementation (2–4 weeks)
- Microsoft 365 Copilot Readiness (2–3 weeks)
- UniFi Network Deployment (1–2 weeks)
- Google to Microsoft Migration (2–6 weeks)
- Incident Response Retainer (monthly / quarterly)

See `/services` for the full catalogue grouped by category.

## Recurring plans

For continuous protection rather than one-off projects:

- **Security Core** — foundational monitoring (vuln management, dark web, M365
  Secure Score, monthly report).
- **Security Plus** — adds attack surface management, BEC protection, SOC-lite,
  tenant management, priority support. *Most popular.*
- **Security Complete** — adds IR retainer, backup assurance, managed Intune,
  vCISO hours, annual pentest, 2-hour SLA.

See `/#pricing` for plan details.

## Picking a service

- **"Are we currently breached?"** → Compromise Assessment (2–3 days).
- **"Our M365 is messy, where do we start?"** → M365 Security Assessment.
- **"We want to deploy Copilot safely."** → Copilot Readiness.
- **"We need a new office network."** → UniFi Full Stack Design.
- **"We keep getting phishing emails."** → BEC Protection or Defender for
  Office 365 Tuning.

When uncertain, suggest the user book a 15-minute fit check at `/contact`.

## Response format

Reply with:

- A one-line answer naming the relevant service.
- The service URL (absolute path).
- Timeframe and what the engagement delivers.
